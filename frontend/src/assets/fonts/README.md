# PDF fonts

Unmodified DejaVu Sans 2.35 TrueType fonts from the DejaVu project:
https://dejavu-fonts.github.io/

- `DejaVuSans.ttf`: regular
- `DejaVuSans-Bold.ttf`: bold
- `DejaVuSans-Oblique.ttf`: italic

All three include Vietnamese characters. They are bundled with the application
and embedded in exported PDFs, without requesting fonts from an external service.
See `LICENSE_DEJAVU` for the redistribution terms.
